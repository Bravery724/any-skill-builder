# Clear Weekly Update

Turn rough project notes into a readable weekly update for people who do not attend the project's meetings.

## Use it

Give the host agent substantive notes or readable source excerpts. You can also supply the reporting period, project name, preferred length or format, evidence links, and confirmed owners or dates. The skill follows your conversation language unless you request another output language.

Once the skill is installed in a host that supports named skills, an example request is:

> Use $clear-weekly-update to write a weekly update from these notes for colleagues outside the project. Keep it concise: the search prototype now supports Korean queries in the test environment; customer rollout timing is still unconfirmed; Mina will review the test feedback next week.

You receive a reviewable update that explains unfamiliar terms, connects supported progress to its meaning, places supplied links beside claims, and marks unresolved facts without inventing commitments. Short updates stay short; facts are not repeated across several sections.

To revise it, say what changed:

> The rollout date is now confirmed as December 3. Update the date and keep the rest unchanged.

For a different source layout:

> Put sources in a short list at the end and keep numbered references beside the claims.

If invoked without notes or usable context, the skill offers brief help and asks for the source material. It does not invent project activity.

## Requirements and limits

No scripts, packages, accounts, or network access are required for pasted notes. Reading attachments or checking remote sources depends on the host's available tools and access. A supplied URL is not automatically verified; ask for source verification when needed. The skill cannot establish missing private facts and does not send, publish, or schedule the draft. Installation into a host is separate from using the supplied folder as instructions.

This package contains SKILL.md, this guide, and the MIT license. It contains no project notes, saved questionnaire answers, or machine-specific paths.
